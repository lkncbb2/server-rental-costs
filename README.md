## 同样是2核2G，为什么有人花38元、有人花99元

差别在三个地方：产品线、带宽类型和流量模型。

产品线不同。轻量机是打包套餐，带宽和盘都是固定搭配；ECS可以自己配带宽计费方式、挂载数据盘、组建内网，功能更全，学习成本也高一点。

带宽类型不同。e实例标注的“3M固定带宽”是保证速率，任何时候都能跑满3M；轻量机的“200M峰值带宽”指最高能冲到的速率，不承诺每一刻都跑满。日常博客和展示型网站用峰值带宽没区别，对接口响应速度有硬性要求的业务，固定带宽更稳。

流量模型不同。阿里云的国内轻量机不限流量；腾讯云的轻量机配的是月流量包，比如它38元那台带300GB/月。要跑下载、大文件分发的业务，这个差别很实际。

**38元一年的服务器是真的吗？**
真的，但有两个前提。一是它属于限时秒杀，阿里云和腾讯云的38元档都要抢，抢不到按68元的常规活动价买；二是这是入门配置——阿里云38元对应2核2G加200M峰值带宽，腾讯云38元对应4核4G加300GB月流量。跑博客和学习项目没问题，正式业务建议往上选。

**续费会不会涨价？**
99计划的99元、199元两档续费不涨价；秒杀特价机以购买页展示的续费价为准，下单前确认那一栏。

**买一年还是买三年？**
业务确定要长期跑，三年打包更省心；项目周期不明朗，先买一年，甚至按月买，试错成本最低。

**内地节点和香港节点怎么选？**
用户主要在国内就选内地节点，网站需要备案；面向海外用户，或者站点还在开发期不想走备案流程，选香港轻量，25元/月起。
